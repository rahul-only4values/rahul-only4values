## How I work

- **Measure, don't guess.** Every number I publish is labelled measured, derived or unverified.
- **An agent fleet writes the code; I direct and review it.** Every commit carries a ticket key, merges are squash-only, and the public repos run an automated audit that blocks leaks.
- **Research first.** Before building agent tooling I swept 358 existing repos and wrote down what was actually worth using.
